# Netflix 2023 Content and Viewership Analysis

## Project Overview
This project explores Netflix content released globally in 2023. The analysis focuses on content types, languages, release dates, and viewing hours to identify patterns in Netflix's content and viewership.

## Objectives
- Clean and prepare the dataset for analysis.
- Analyze Netflix content released in 2023.
- Compare viewing hours across movies and shows.
- Identify the most-viewed titles.
- Explore content distribution by language and release timing.
- Present key findings through data visualizations.

## Dataset
The dataset contains information about Netflix titles, including:
- Title
- Global availability
- Release date
- Hours viewed
- Language indicator
- Content type

The original dataset contained **24,812 rows and 6 columns**. Data cleaning included handling duplicate records, converting release dates into a date format, and converting viewing hours into numeric values.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Data inspection and cleaning
- Duplicate record analysis
- Release-date and viewing-hours preparation
- Analysis of 2023 releases
- Comparison of movies and shows
- Language-based content analysis
- Identification of top-viewed titles
- Release timing analysis and visualizations

## Key Findings
- The Night Agent: Season 1 recorded approximately **812.1 million viewing hours**.
- Ginny & Georgia: Season 2 recorded approximately **665.1 million viewing hours**.
- King the Land: Limited Series recorded approximately **630.2 million viewing hours**.
- The Glory: Season 1 recorded approximately **622.8 million viewing hours**.
- ONE PIECE: Season 1 recorded approximately **541.9 million viewing hours**.
- Shows accounted for approximately **68%** of the content in the Power BI overview, compared with 32% for movies.
